## Ce que j'ai construit

Un site d'une seule page, volontairement minimaliste, en **HTML, CSS et JavaScript vanilla** (Bootstrap uniquement pour la grille).

- mes projets sont chargés en direct depuis l'API GitHub
- un curseur personnalisé qui s'aimante aux liens
- des animations qui respectent le réglage « réduire les animations » du système
- un site pensé pour le mobile d'abord
- un compteur de visites sans cookie ([GoatCounter](https://www.goatcounter.com/))

Pour le voir en local, il suffit d'ouvrir `index.html` dans un navigateur : rien à installer.
